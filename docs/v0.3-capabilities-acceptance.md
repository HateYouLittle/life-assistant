## 5. 回滚方案

| 场景 | 操作 |
|---|---|
| 代码问题，未升级 schema | `git reset --hard 14dbf3b` 或切换回原部署，重启即可 |
| schema 已升级（version=5） | **必须连库一起回退**：停服务 → 还原 3.1 的 v4 备份 → 部署旧代码 → 启动后确认 `version == 4`。旧代码打开 v5 库会直接拒绝 |
| 仅个别新功能异常 | 优先禁掉对应模块（如注释 `src/modules/index.ts` 中 airquality/automation/assistant 导入）而非整体回退；通知静默/snooze 依赖 `not_before` 列，字段空值即旧行为 |
